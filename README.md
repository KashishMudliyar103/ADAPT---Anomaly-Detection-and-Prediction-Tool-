## 📌 Problem Statement

Insider threats and external cyberattacks often leave subtle traces in system logs — unusual login times, unexpected file access, excessive failed attempts, or data exfiltration patterns. Security analysts face the challenge of detecting these needles in massive haystacks of log data **without labeled training data**.

**ADAPT** solves this with a fully unsupervised ML pipeline that:
1. Profiles user behavior automatically
2. Clusters entities into behavioral archetypes
3. Flags deviations as **Normal / Suspicious / Risky**
4. Surfaces insights through an interactive analyst dashboard

## ✨ Features

| Feature | Description |
|---|---|
| **Multi-model Detection** | K-Means + DBSCAN + Isolation Forest in ensemble |
| **Behavioral Profiling** | Per-user aggregated risk profile (fail rate, unique IPs, event velocity) |
| **3-Tier Risk Labeling** | Normal → Suspicious → Risky with configurable thresholds |
| **Interactive Dashboard** | 6-tab Streamlit app with drill-down capabilities |
| **Time-Series Analysis** | Daily trend lines + day×hour heatmap |
| **Entity Profiler** | Per-user investigation panel with activity timeline |
| **DBSCAN Outlier View** | Noise-point isolation for rare attack pattern detection |
| **Export** | One-click CSV export of filtered events |
| **Offline Evaluation** | `evaluate.py` with classification metrics vs ground truth |

## 🚀 Quick Start

### 1. Clone & install

```bash
git clone https://github.com/<your-username>/ADAPT.git
cd ADAPT
pip install -r requirements.txt
```

### 2. Launch the dashboard

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

### 3. Offline evaluation (optional)

```bash
python evaluate.py --data data/cybercrime_forensic_dataset.csv
```

This prints classification metrics and saves a confusion matrix to `assets/`.

## 🔬 ML Methodology

### Feature Engineering (14 features)
| Feature | Type | Description |
|---|---|---|
| `login_attempts_norm` | Numeric | Scaled login attempt count |
| `file_size_norm` | Numeric | Scaled file operation size |
| `hour_sin / hour_cos` | Temporal | Cyclical encoding of hour-of-day |
| `is_failed_action` | Binary | Whether action was a failure |
| `is_remote` | Binary | Remote login activity flag |
| `is_file_op / is_network_op / is_usb` | Binary | Activity type flags |
| `is_external_ip` | Binary | Non-RFC-1918 IP address |
| `user_event_rate` | Behavioral | Normalized event frequency per user |
| `user_fail_rate` | Behavioral | Fraction of failed actions per user |
| `user_unique_ips` | Behavioral | Normalized unique IP count per user |
| `anomaly_score` | Composite | Weighted heuristic pre-model score |

### Risk Tier Logic
```
Risky      →  DBSCAN noise point  OR  (IsoForest anomaly AND score ≥ P90)
Suspicious →  K-Means "riskiest cluster"  OR  score ≥ P75
Normal     →  everything else
```

## 📊 Dataset

The system ships with the **Cybercrime Forensic Dataset** containing:
- **7,400** user log events
- **11** raw features: Timestamp, User_ID, IP_Address, Activity_Type, Resource_Accessed, File_Name, Action, Login_Attempts, File_Size, Anomaly_Type, Label
- **7 activity types**: File_Access, Network_Traffic, Login, Remote_Login, File_Modification, File_Deletion, USB_Insert
- **4 anomaly types**: Brute_Force, DDoS_Attempt, Data_Exfil, USB_Access
- Ground-truth labels (Normal / Suspicious) for offline evaluation
